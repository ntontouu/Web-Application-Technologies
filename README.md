## Overview
An introductory project demonstrating the fundamental building blocks of web development. This assignment focuses on structuring a webpage using semantic HTML tags and styling it with internal CSS.

## Features
- **Forms:** Implementation of a user input form utilizing text fields, dropdown (`<select>`), and submit buttons for querying student data.
- **Tables:** Construction of a formatted data table presenting student information.
- **CSS Styling:** Application of structural styling, including table borders, customized header backgrounds, and alternating row colors (zebra-striping) using the `nth-child` pseudo-class.
