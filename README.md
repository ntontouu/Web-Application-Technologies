## Overview
This exercise explores dynamic client-side scripting by utilizing JavaScript to interact with and modify the Document Object Model (DOM) of an HTML page.

## Core Concepts Implemented
- **External Scripts:** Linking an external `.js` file to an HTML document to separate structure from behavior.
- **DOM Selection:** Utilizing `getElementById` and `querySelector` to target specific HTML elements.
- **Content Modification:** Dynamically altering the `textContent` property of elements upon script execution.
- **Dynamic Styling:** Assigning predefined CSS classes to elements dynamically via the `className` property to alter their visual state.
